# media/ (lokal)

Dieser Ordner liegt **nur auf dem Windows-PC**.

GitHub speichert hier keine Filme, keine Cover und keine MP4s.

Lege deine Inhalte lokal ab:

- `films/` – HTML-Filme
- `covers/` – Cover
- `intros/` – Intro
- `subtitles/` – VTT
- Video-Dateien als `.mp4` (oder absoluter Pfad in `metadata/videos.json`)
